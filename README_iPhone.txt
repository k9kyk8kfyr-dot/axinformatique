AXinfo Ultimate v17.1 — Dynamic iPhone + PC Bridge

WHAT'S NEW
- Responsive layout adapts to iPhone, Android, tablet and desktop widths.
- Safe-area support for iPhone notch / Dynamic Island / Home Indicator.
- Landscape support on phones and tablets.
- Touch-friendly controls.
- Fixed and hardened PWA manifest + Service Worker.
- New Settings > "ربط الهاتف بالحاسوب".
- Optional local-Wi-Fi PC Bridge for sending/getting AXinfo JSON data.

PC CONNECTION
1. On Windows install Python 3 if needed.
2. Put this folder on the PC.
3. Double-click START_AXinfo_PC.bat.
4. Keep the black window open.
5. The window displays a PC address like http://192.168.1.20:8765 and a pairing token.
6. On the phone, open AXinfo > الإعدادات > ربط الهاتف بالحاسوب.
7. Enter the PC address and token.
8. Tap "اختبار الاتصال".
9. Use "إرسال بيانات الهاتف إلى PC" or "جلب آخر نسخة من PC".

IMPORTANT
- Phone and PC must be on the same Wi-Fi for the PC Bridge.
- This bridge is a local-network sync/backup mechanism, not a public cloud service.
- The GitHub Pages PWA is still the easiest way to install AXinfo on iPhone.
- Keep the original AXinfo localStorage data; the upgrade uses the same AXinfo database keys.

PWA
Open the GitHub Pages site in Safari, then Share > Add to Home Screen.
