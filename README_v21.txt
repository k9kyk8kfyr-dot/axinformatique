AXinfo v21 — Offline + iPhone + PC + Automatic Two-Way Sync

1) Windows: run START_AXinfo_PC.bat and keep it open while using live sync.
2) The PC Bridge shows the local PC address and pairing token.
3) Phone and PC work offline independently.
4) When both can reach the PC Bridge on the local network, AXinfo automatically syncs changes in both directions.
5) Open AXinfo on the PC from http://PC_ADDRESS/index.html if you want the PC to edit the same data store.
6) In Settings > PC connection, save the address and token once. The connection state persists while navigating between sections.
7) Automatic sync runs periodically and also after local changes. Manual Send/Get buttons remain available.
8) If both devices change the same data while disconnected, the latest local snapshot pushed to the bridge can replace the previous snapshot. Use backup/export before major offline work.
9) GitHub Pages (HTTPS) may block direct HTTP local requests. For reliable local sync, use the PC-local URL served by the Bridge.
