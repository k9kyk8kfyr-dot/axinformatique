AXinfo Ultimate v22 — Offline + Auto Sync + Multilingual

1) PC: double-click START_AXinfo_PC.bat.
2) Keep the black window open while using live sync.
3) The PC will show its local address and pairing token.
4) Phone and PC must have a local network path for live sync (same Wi-Fi or a PC hotspot). Internet is not required.
5) In AXinfo > Settings > PC connection, enter the PC address and token, then save.
6) Auto Sync runs in the background while AXinfo is open. The connection badge is global and remains while navigating sections.
7) For fully offline use, each device keeps its own local data. Use backup/restore when there is no network path.

Languages: Arabic, French, English, Spanish, German, Italian, Portuguese, Turkish, Russian, Chinese, Japanese, Korean, Dutch, Indonesian, Hindi for the main interface. User-entered customer/product names are preserved.
